# Mission (stub)

Build verified, provenance-carrying synthetic tutoring datasets for post-training: dialogues where a tutor diagnoses a student's specific misconception, guides with a hint ladder instead of giving the answer, and confirms the fix. Every problem answer is checked independently before any row exists. Owned by the pivot epic [#4](https://github.com/rmems/AI-ML-SWE-synthetic-tutor/issues/4).
