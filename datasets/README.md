# datasets/

Build outputs, one folder per dataset family (`datasets/<family>/`), each produced by one generator config and carrying one dataset-card draft. Rows are only written by `crates/tutor-build` after verification, and every row carries provenance (generator, seed, runtime versions, verifier). Generated rows are gitignored; only `README.md` and dataset-card drafts (`datasets/<family>/CARD.md`) are committed. Every pipeline run that commits a batch also appends to its output directory's `run-log.jsonl` (the append-only generation run log — [docs/cadence.md](../docs/cadence.md), `schemas/run-log.schema.json`). `datasets/gold/` holds the hand-written gold exemplar rows, which are committed. Never write rows to the repo root or to notes folders.
