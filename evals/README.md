# evals/

Held-out evaluation material and the rubric used to grade tutor dialogues. `heldout/` holds items that must never appear in training splits; `crates/tutor-build` decontaminates against it ([#8](https://github.com/rmems/AI-ML-SWE-synthetic-tutor/issues/8)). [rubric.md](rubric.md) is the grading rubric.
